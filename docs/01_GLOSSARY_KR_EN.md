## 1. AI & 기술 핵심 개념 (AI & Tech Fundamentals)

| 영문 용어 (English Term) | 한국어 의미 | 비즈니스 컨텍스트 및 핵심 설명 |
| :--- | :--- | :--- |
| **Artificial Intelligence (AI)** | 인공지능 | 인간의 지능적 행동(학습, 추론, 문제해결)을 시뮬레이션하는 포괄적인 기술 범주 |
| **Machine Learning (ML)** | 기계 학습 | 명시적 프로그래밍 없이 데이터로부터 패턴을 학습하여 예측이나 판단을 수행하는 AI의 하위 분야 |
| **Generative AI (GenAI)** | 생성형 AI | 기존 데이터를 학습하여 새로운 텍스트, 이미지, 코드, 오디오 등을 창작·생성하는 모델 (예: LLM) |
| **Foundation Model (FM)** | 파운데이션 모델 | 방대한 비라벨 데이터로 사전 학습되어 다양한 다운스트림 작업(요약, 질의응답, 번역 등)에 적응 가능한 대규모 모델 |
| **Large Language Model (LLM)** | 대규모 언어 모델 | 수십억 개 이상의 매개변수와 방대한 텍스트로 학습된 자연어 생성 및 이해 특화 모델 |
| **Inference (추론)** | 추론 / 예측 실행 | 학습된 모델을 실제 운영 환경에 배치하여 새로운 입력 데이터에 대해 예측이나 출력을 생성하는 과정 |
| **Structured Data** | 정형 데이터 | 관계형 DB(RDBMS), 엑셀 시트처럼 고정된 스키마와 행/열 형식을 갖춘 데이터 |
| **Unstructured Data** | 비정형 데이터 | 이메일, PDF 문서, 고객 상담 녹취록, 이미지 등 사전 정의된 모델이 없는 데이터 (GenAI 활용도 높음) |
| **Context Window** | 컨텍스트 윈도우 | 모델이 한 번의 프롬프트 처리 과정에서 기억하고 참조할 수 있는 최대 토큰(단어 조각) 범위 |
| **Token Limit** | 토큰 제한 | 모델 입력 및 출력의 최대 허용 토큰 수 제약. 길어질수록 비용과 지연시간(Latency) 증가 |
| **Prompt Engineering** | 프롬프트 엔지니어링 | 모델 재학습 없이 지시문(프롬프트) 설계를 통해 모델의 출력 품질과 일관성을 최적화하는 기법 |
| **In-Context Learning / Few-Shot** | 인컨텍스트 학습 / 퓨샷 | 프롬프트 안에 2~3개의 모범 입출력 예시를 포함시켜 모델이 원하는 형식대로 응답하도록 유도하는 방식 |
| **Retrieval-Augmented Generation (RAG)** | 검색 증강 생성 | 모델 자체를 재학습하지 않고, 외부 지식 베이스(사내 문서/DB)에서 관련 정보를 실시간 검색하여 프롬프트 컨텍스트에 주입해 응답을 생성하는 기법 |
| **Fine-Tuning (미세 조정)** | 파인 튜닝 | 사전 학습된 파운데이션 모델에 특정 도메인의 라벨링된 데이터를 추가 학습시켜 가중치를 조정하는 기법 (비용·시간 소요) |
| **Rule-Based Automation** | 규칙 기반 자동화 | 명확한 IF-THEN 로직이나 정해진 절차에 따라 동작하는 자동화(RPA 등). 결정론적이고 예외가 적은 업무에 적합 |
| **AI Agent** | AI 에이전트 | 자율적으로 목표를 인식하고, 계획(Planning)을 세우며, 도구(Tool/API)를 호출하고, 복잡한 다단계 작업을 완수하는 지능형 시스템 |
| **Model Drift / Concept Drift** | 모델 드리프트 | 시간 경과에 따라 실제 데이터의 분포나 비즈니스 환경이 변화하여 모델의 예측 정확도가 저하되는 현상 |

## 2. 전략, 비즈니스 가치 & 재무 (Strategy, Value & Financials)

| 영문 용어 (English Term) | 한국어 의미 | 비즈니스 컨텍스트 및 핵심 설명 |
| :--- | :--- | :--- |
| **Build vs Buy vs Partner** | 자체 개발 vs 기성품 구매 vs 파트너 협력 | AI 솔루션 도입 시 TCO, 출시 속도(Time to Market), 핵심 역량 유출 여부, 규제 준수 등을 고려한 전략적 의사결정 프레임워크 |
| **Total Cost of Ownership (TCO)** | 총 소유 비용 | 초기 구축비뿐 아니라 인프라 운영비, API 호출 비용, 데이터 라벨링 및 지속적 유지보수 비용을 포함한 전체 비용 |
| **Baseline Metric** | 기준 지표 | AI 도입 전후의 효과를 정량적으로 비교·측정하기 위해 사전에 수집·정의하는 현재 성과 기준치 |
| **Tangible Benefits** | 유형적 이익 | 비용 절감(시간 단축, 인건비 효율화), 직접 매출 증가 등 재무제표에 숫자로 바로 증명 가능한 성과 |
| **Intangible Benefits** | 무형적 이익 | 고객 만족도(CSAT/NPS) 상승, 직원 업무 만족도 향상, 브랜드 혁신 이미지 제고 등 간접적 가치 |
| **Leading Indicator** | 선행 지표 | 최종 비즈니스 성과(매출, ROI)가 나타나기 전에 프로젝트의 성공 가능성을 미리 예측할 수 있는 초기 지표 (예: 사용자 채택률, 일일 활성 사용자 수, 쿼리 수) |
| **Lagging Indicator** | 후행 지표 | 프로젝트가 완료되거나 일정 기간이 지난 후에야 측정할 수 있는 결과 지표 (예: 연간 비용 절감액, 분기 매출 증대) |
| **Return on Investment (ROI)** | 투자 수익률 | (AI 도입으로 얻은 순이익 ÷ 총 투자 비용) × 100. AI 투자 타당성을 입증하는 핵심 재무 지표 |
| **Time to Market (TTM)** | 시장 출시 기간 | 아이디어 발굴부터 실제 프로덕션 릴리스까지 걸리는 시간. 상용 솔루션(Buy)이 가장 빠름 |
| **Data Flywheel** | 데이터 플라이휠 | 사용자가 늘어날수록 양질의 사용자 데이터가 축적되고, 이를 통해 모델이 고도화되어 다시 더 많은 사용자를 유치하는 선순환 구조 |

## 3. 거버넌스 & 책임 있는 AI (Governance & Responsible AI)

| 영문 용어 (English Term) | 한국어 의미 | 비즈니스 컨텍스트 및 핵심 설명 |
| :--- | :--- | :--- |
| **Responsible AI (RAI)** | 책임 있는 AI | AI 시스템을 안전하고, 윤리적이며, 공정하고 신뢰할 수 있게 설계·배포·운영하는 전사적 원칙 및 실천 방안 |
| **Hallucination** | 환각 현상 | 모델이 그럴듯하지만 사실이 아니거나 왜곡된 정보를 확신을 가지고 생성해내는 오류 |
| **Guardrails** | 가드레일 | 유해 콘텐츠 차단, 개인 식별 정보(PII) 마스킹, 지정된 주제 외 이탈 방지 등을 위해 모델의 입출력을 실시간 검사하는 보호 정책 |
| **Human-in-the-Loop (HITL)** | 인간 참여형 검증 | 최종 의사결정이나 고위험 작업(예: 대출 심사, 채용, 의료 판독) 시 인간 전문가의 검토 및 승인 단계를 필수적으로 배치하는 구조 |
| **Bias & Fairness** | 편향성과 공정성 | 학습 데이터나 알고리즘에 내재된 왜곡으로 인해 특정 인구 집단이나 범주에 불리한 결과가 도출되지 않도록 하는 원칙 |
| **Explainability / Interpretability** | 설명 가능성 / 해석 가능성 | AI 모델이 왜 그러한 예측이나 결정을 내렸는지 이해관계자 및 규제 기관에 명확히 설명할 수 있는 역량 |
| **Shadow AI** | 섀도 AI | 회사의 공식 승인이나 보안 통제 없이 직원들이 외부 상용 AI 도구(무료 챗봇 등)에 사내 기밀 데이터를 입력하여 사용하는 보안 위협 |
| **Personally Identifiable Information (PII)** | 개인 식별 정보 | 이름, 주민등록번호, 이메일, 전화번호 등 특정 개인을 식별할 수 있는 민감 데이터 |
| **Intellectual Property (IP) Infringement** | 지적 재산권 침해 | GenAI 모델이 저작권으로 보호되는 원작자의 텍스트/이미지를 무단 복제하여 법적 분쟁을 일으키는 위험 |
| **Cross-Functional Governance** | 다학제적 거버넌스 | IT/엔지니어링뿐만 아니라 법무(Legal), 컴플라이언스(Compliance), 비즈니스 리더, HR 등이 참여하는 전사 AI 거버넌스 협의체 |
| **ISO/IEC 42001** | 인공지능 경영시스템 표준 | 조직이 책임감 있게 AI를 개발하고 활용하도록 요구하는 최초의 국제 공인 AI 경영시스템 인증 표준 |

## 4. 조직 준비성 & 변화 관리 (Readiness & Change Management)

| 영문 용어 (English Term) | 한국어 의미 | 비즈니스 컨텍스트 및 핵심 설명 |
| :--- | :--- | :--- |
| **AI Center of Excellence (CoE)** | AI 우수성 센터 (AI CoE) | 전사 AI 전략 수립, 모범 사례 전파, 기술 지원 및 거버넌스 표준을 총괄하는 중앙 전문 조직 |
| **AI Champions** | AI 챔피언 | 각 사업 부서에서 AI 도입을 적극 홍보하고, 팀원들의 실무 활용을 독려하며 현장 피드백을 전달하는 핵심 인재 |
| **Culture of Experimentation** | 실험 문화 | 작은 실패를 용인하고 빠른 가설 검증과 반복적(iterative) 학습을 장려하는 조직 문화 |
| **Data Silos** | 데이터 사일로 | 부서 간 데이터가 고립되어 전사적 공유나 통합 분석이 불가능한 상태 (AI 확장 시 최대 걸림돌) |
| **Proof of Concept (PoC)** | 개념 증명 | 본격적인 투자에 앞서 특정 기술이나 아이디어의 실현 가능성을 소규모로 단기간에 검증하는 프로젝트 |
| **Pilot to Production Scaling** | 파일럿에서 전사 배포로의 확장 | Envision(구상) ➔ Experiment(실험) ➔ Launch(출시) ➔ Scale(확장) 단계로 체계적으로 확산하는 전략 |
